# Security

## Reporting a vulnerability

Report it privately through GitHub: open the **Security** tab of this repo and click **Report a vulnerability**, or go straight to https://github.com/unico-labs/reference-apps/security/advisories/new.

Don't open a public issue or pull request for a vulnerability.

Problems in the Unico API or Unico's SDKs themselves go through the same channel, or to your Unico contact.

## What these apps are

These are reference apps. In demo mode, the mobile apps keep the credentials on the device so you can try them without a server. That's a shortcut for trying the app, not a vulnerability to report. In production, the service account key lives only on your server: see the [hard rules in `AGENTS.md`](AGENTS.md#hard-rules).
